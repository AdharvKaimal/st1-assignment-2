REFLECTION (STAGE 04)  

The further implementation of the classes from Stage03 was continued here in Stage04.
I found that the implementation of the classes, without AI, using regular Python OOP
was straightforward and could be implemented gradually using the UML structure that
was planned.  
In terms of the AI, I found that it overcomplicated the OOP process for the
implementation of the APPOINTMENT Class. Though the implementation was mostly correct,
it further assumed additional requirements and grew the scope to additional libraries,
helper functions, and more complex data classes. Whereas the same result can be
achieved in a simpler, less presumptive way using simplified Python OOP. I generally
approved the design of the class methods themselves, whist discarding the additional
functionality that was implemented based on assumptions or over complication. Finally,
the AI didn't necessarily implement any tests or additional validation, which is also
an issue in terms of testing and reliability. In my manual implementation, I made sure
to implement all of these changes.
